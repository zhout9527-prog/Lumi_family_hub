# Cover asset sources

The local demo covers are resized copies of photos served by Unsplash. Their source identifiers are retained as file names so a source can be located at:

`https://unsplash.com/photos/<identifier-without-the-photo-prefix>`

They are illustrative category covers for the prototype and are not official artwork for the named programs or books. Usage is subject to the Unsplash License:

`https://unsplash.com/license`
